## Shared integration

Programming, backend, frontend, SQL, containers and AI retain deep implementation ownership in their specialized repositories. Fullstack links them through one system model.

## Canonical rule

Every master-list item has one primary home. Do not create duplicate courses. If a topic crosses domains, keep the concept and trade-off explanation here and link to the specialized implementation source.

## Completion gate

A capability is only considered finished when it can be understood, implemented, debugged, measured, secured, tested, scaled, operated and defended.
