# Fastify

**Role:** Primary | **Layer:** TypeScript backend

## Mental model
Fastify is a low-overhead Node.js web framework organized around routes, schemas, hooks, plugins and encapsulated application context.

## Learn
- route registration
- lifecycle hooks
- plugins and encapsulation
- request/reply APIs
- JSON Schema and serialization
- error handling
- logging and request IDs

## Production
Validate at boundaries, keep handlers thin, move business logic into application/domain modules, use structured logs, define timeouts, and make error responses stable.

## Related
Node.js, TypeScript, Zod, OpenAPI, PostgreSQL, Pino.
