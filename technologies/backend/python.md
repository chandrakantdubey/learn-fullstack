# Python

**Role:** Primary | **Layer:** Backend/AI

## Mental model
Python is a dynamically typed language with strong introspection, automatic memory management and a broad ecosystem. Type hints improve tooling and design but do not themselves validate runtime data.

## Learn
- data model and object protocols
- functions, closures and decorators
- iterators/generators
- exceptions and context managers
- typing and protocols
- modules and packaging
- asyncio and concurrency
- profiling and memory behavior

## Production
Use explicit types at service boundaries, virtual environments/locked dependencies, structured logging, bounded concurrency and clear sync/async ownership.

## Related
FastAPI, Pydantic, SQLAlchemy, pytest, PyTorch.
