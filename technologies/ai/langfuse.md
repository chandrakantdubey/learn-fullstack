# Langfuse

**Role:** Primary | **Layer:** LLM observability/evaluation

## Mental model
Langfuse captures LLM traces, prompts, generations, costs, latency and evaluation signals so AI applications can be debugged and improved systematically.

## Learn
- traces and observations
- prompt/version tracking
- token/cost accounting
- datasets and evaluations
- scores and annotations
- production monitoring

## Production
Capture model/provider/version, latency, token usage and relevant workflow metadata while redacting sensitive content. Build evaluations from representative datasets rather than relying on anecdotal quality.

## Related
OpenTelemetry, OpenAI SDK, LangGraph, RAG, evals.
