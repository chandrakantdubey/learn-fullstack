# Hugging Face Transformers

**Role:** Primary | **Layer:** AI/ML

## Mental model
Transformers provides reusable model architectures, tokenizers and pretrained checkpoints for modern NLP, vision and multimodal workloads.

## Learn
- tokenization and attention masks
- model/config/tokenizer separation
- pretrained inference
- fine-tuning and parameter-efficient tuning
- generation parameters
- quantization concepts
- model loading and device placement

## Production
Pin model revisions, validate tokenizer/model compatibility, measure memory and latency, cache artifacts safely, and treat model files as supply-chain inputs.

## Related
PyTorch, sentence-transformers, vLLM, RAG.
