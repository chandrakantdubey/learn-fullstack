# sentence-transformers

**Role:** Primary | **Layer:** AI/embeddings

## Mental model
Sentence Transformers produces dense vector representations designed so semantically related text can be compared by distance.

## Learn
- encoder models
- embedding dimensions
- pooling
- similarity metrics
- semantic search
- multilingual embeddings
- batching and GPU inference

## Production
Version embedding models, store model identity with vectors, benchmark retrieval on representative queries, batch inference, and plan re-embedding when models change.

## Related
pgvector, RAG, Hugging Face Transformers, OpenAI SDK.
