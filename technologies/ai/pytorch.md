# PyTorch

**Role:** Primary | **Layer:** AI/ML

## Mental model
PyTorch represents computation as tensor operations and dynamically builds computation graphs for automatic differentiation. Models are programs mapping tensors to outputs with learned parameters.

## Learn
- tensors and devices
- autograd
- modules and parameters
- datasets and dataloaders
- training/evaluation modes
- optimizers and schedulers
- mixed precision
- distributed training
- checkpointing

## Production
Control memory, batch sizes and device placement; save reproducible checkpoints; separate training from inference code; measure latency/throughput; and validate model artifacts before deployment.
