# Testing Library

**Role:** Primary | **Layer:** Frontend testing

## Mental model
Testing Library encourages tests that interact with UI through user-observable behavior instead of component implementation details.

## Learn
- semantic queries
- roles, labels and accessible names
- user-event interactions
- async assertions
- test isolation
- custom render helpers

## Production
Prefer accessible queries, test real user flows, avoid querying internal class names, and use mocks only where external boundaries require them.

## Related
React, Vitest, Playwright, accessibility.
