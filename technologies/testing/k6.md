# k6

**Role:** Primary | **Layer:** Performance testing

## Mental model
k6 generates programmable load so teams can measure latency, throughput, errors and resource behavior under defined traffic models.

## Learn
- virtual users
- ramping scenarios
- thresholds
- checks and custom metrics
- HTTP/WebSocket load
- test data and environment control

## Production
Define workload assumptions first, set SLO-based thresholds, test gradually, correlate results with server metrics/traces, and distinguish capacity limits from client-side bottlenecks.

## Related
Prometheus, Grafana, Kubernetes, autoscaling.
