# Playwright

**Role:** Primary | **Layer:** End-to-end testing

## Mental model
Playwright automates real browser engines to test user journeys, network behavior and browser-facing application contracts.

## Learn
- locators and assertions
- fixtures and test isolation
- browser contexts
- authentication state
- network interception
- parallelism
- traces/screenshots/video

## Production
Prefer resilient semantic locators, isolated test data, deterministic environments and a small set of high-value end-to-end journeys. Use traces to diagnose failures instead of adding sleeps.

## Related
React, Next.js, Testing Library, CI/CD.
