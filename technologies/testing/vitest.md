# Vitest

**Role:** Primary | **Layer:** Testing

## Mental model
Vitest is a fast Vite-native test runner for unit and integration tests, with mocking, assertions and coverage support.

## Learn
- test lifecycle
- assertions
- mocks/spies
- fake timers
- module mocking
- coverage
- environment configuration

## Production
Test behavior and contracts, keep unit tests deterministic, mock external systems at clear boundaries, and use integration tests for database/API wiring rather than mocking everything.

## Related
TypeScript, React, Testing Library, Playwright.
