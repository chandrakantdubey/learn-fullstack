# CodeQL

**Role:** Primary | **Layer:** Application security

## Mental model
CodeQL treats source code as queryable data so security queries can detect vulnerability patterns beyond simple text matching.

## Learn
- databases and query concepts
- security query packs
- taint/data-flow analysis
- source/sink modeling
- CI integration

## Production
Run analysis in CI, triage findings by exploitability and reachability, suppress only with documented justification, and keep queries/tooling maintained.
