# Trivy

**Role:** Primary | **Layer:** Security/supply chain

## Mental model
Trivy scans container images, filesystems and configuration for vulnerabilities and security issues.

## Learn
- image vulnerability scanning
- dependency and filesystem scanning
- IaC misconfiguration checks
- severity and exception handling
- CI integration

## Production
Scan built artifacts, fail CI on an agreed severity policy, keep databases/current scanners updated, and manage exceptions with ownership and expiration.

## Related
Docker, Kubernetes, Terraform, GitHub Actions.
