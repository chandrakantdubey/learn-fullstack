# OWASP

**Role:** Primary | **Layer:** Security

## Mental model
OWASP is a security knowledge ecosystem. Use its guidance to reason about common application risks, controls and secure development practices.

## Learn
- injection
- broken authentication and authorization
- security misconfiguration
- cryptographic failures
- SSRF
- insecure deserialization/software supply chain risks
- XSS/CSRF and browser security
- API security

## Production
Threat-model trust boundaries, validate input, parameterize database access, enforce authorization server-side, protect secrets, set secure headers, rate-limit sensitive operations, and log security events without leaking sensitive data.

## AI applications
Add prompt injection, tool authorization, data exfiltration, unsafe output handling and tenant isolation to normal application threat models.
