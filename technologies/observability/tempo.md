# Grafana Tempo

**Role:** Awareness | **Layer:** Tracing

## Mental model
Tempo is a distributed tracing backend designed to store and query traces with strong integration into the Grafana observability stack.

## Learn
- trace storage and querying
- TraceQL concepts
- OpenTelemetry ingestion
- metrics/logs/traces correlation
- retention and sampling

## Production
Control retention and sampling, propagate trace context correctly, and use trace-to-log/metric links to move from symptoms to root cause.
