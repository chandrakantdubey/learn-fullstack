# OpenTelemetry

**Role:** Primary | **Layer:** Observability

## Mental model
OpenTelemetry provides vendor-neutral instrumentation and data models for traces, metrics and logs. It separates telemetry production from the backend that stores/visualizes it.

## Learn
- traces, spans and context propagation
- metrics and instruments
- logs and correlation
- resource/service attributes
- SDKs and collectors
- sampling
- baggage and propagation

## Production
Propagate trace context across HTTP and messaging, use stable service/resource attributes, control cardinality, sample intelligently, and never place secrets or sensitive payloads into telemetry.

## Related
Prometheus, Grafana, Pino, Jaeger, Tempo.
