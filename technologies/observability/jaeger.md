# Jaeger

**Role:** Awareness | **Layer:** Tracing

## Mental model
Jaeger is a distributed tracing backend and UI used to inspect request traces, span timing and service dependencies.

## Learn
- trace/span model
- service maps
- latency breakdowns
- sampling
- OpenTelemetry integration

## Production
Use trace IDs consistently, sample high-volume traffic intelligently, retain enough traces for incident investigation, and avoid sensitive span attributes.
