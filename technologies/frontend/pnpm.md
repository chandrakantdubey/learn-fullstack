# pnpm

**Role:** Primary | **Layer:** Package management

## Mental model
pnpm uses a content-addressable store and links dependencies into projects, reducing duplication while keeping package boundaries explicit.

## Learn
- workspaces
- lockfiles and reproducible installs
- dependency categories
- scripts and lifecycle hooks
- overrides and package extensions
- monorepo filtering

## Production
Commit the lockfile, use frozen installs in CI, pin Node/package-manager versions, review dependency changes, and understand workspace dependency boundaries.

## Related
Node.js, TypeScript, Vite, GitHub Actions, monorepos.
