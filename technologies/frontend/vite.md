# Vite

**Role:** Primary | **Layer:** Frontend tooling

## Mental model
Vite provides fast development through native-module serving and uses a production bundler pipeline for optimized assets.

## Learn
- dev server and dependency pre-bundling
- plugins and configuration
- environment variables
- asset handling
- build output and source maps
- library mode

## Production
Keep environment configuration explicit, inspect bundle output, avoid leaking secrets into client variables, and understand the distinction between development behavior and production builds.

## Related
React, TypeScript, pnpm, Vitest.
