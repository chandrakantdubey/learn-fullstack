# Radix UI

**Role:** Primary | **Layer:** Frontend

## What it is
Radix UI provides accessible, unstyled primitives for common interactive components.

## Learn
Understand controlled/uncontrolled APIs, portals, focus management, keyboard interaction, ARIA behavior, composition and styling boundaries.

## Production
Use primitives when accessibility and interaction behavior are non-trivial. Preserve semantic HTML and test keyboard and screen-reader-relevant behavior. Do not assume a styled component is accessible merely because its primitive is.

## Related
React, shadcn/ui, Tailwind CSS, Testing Library.
