# shadcn/ui

**Role:** Primary | **Layer:** Frontend

## Mental model
shadcn/ui is a distribution approach for reusable UI components built from accessible primitives, where component source is copied into the application and owned by the team.

## Learn
- component composition
- variants and class composition
- accessibility defaults
- form, dialog, popover and table patterns
- design tokens and customization

## Production
Own the copied source deliberately, keep variants consistent, and test behavior rather than snapshots of generated markup. Pair with a coherent design system instead of collecting unrelated components.

## Related
Radix UI, React, Tailwind CSS, React Hook Form.
