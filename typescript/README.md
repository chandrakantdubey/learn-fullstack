# TypeScript Engineering Track

This section is TypeScript in the context of production Fullstack Engineering.

## Scope

- JavaScript runtime model
- TypeScript type system
- Strict typing and type narrowing
- Generics and reusable contracts
- Modules and package boundaries
- Node.js runtime
- Async I/O and event loop behavior
- HTTP services
- Validation with Zod
- Fastify / Node application structure
- Database access
- Testing with Vitest/Jest
- Browser application architecture
- React and Next.js boundaries
- Build tooling and package management
- Production Node.js deployment

```text
JavaScript runtime

TypeScript
  ↓
Node.js

Fastify
  ↓

  ↓

  ↓
```
