# Frontend Engineering

Frontend engineering is more than React. It starts with the web platform and ends with a reliable, accessible, fast user experience.

## Core areas

- HTML semantics and accessibility
- CSS layout, cascade, responsive design, and rendering
- JavaScript runtime and browser APIs
- TypeScript and type-safe application boundaries
- Component architecture
- State and server-state management
- Data fetching and mutation flows
- Routing and navigation
- Forms and validation
- Error, loading, and empty states
- SSR, SSG, streaming, and client/server boundaries
- Performance and Core Web Vitals
- Browser security
- Testing and end-to-end automation
- Design systems

## Architecture model

```text
Browser platform
     ↓
Application shell
     ↓
UI components
     ↓
Feature state / server state
     ↓
API client
     ↓
Backend contract
```

React and Next.js are implementation choices. The web platform and frontend architecture remain the durable knowledge.
